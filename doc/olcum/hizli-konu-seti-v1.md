# Hızlı çeviri konu seti v1

Kaynak: kullanıcı, DAI — Adım 8 (2026-11-19). Metinler birebir korunmuştur. Bu set yalnız ölçüm içindir; hiçbir ayar bu metinlere göre yapılmamıştır.
